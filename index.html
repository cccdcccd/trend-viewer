トレンドネタ

設定

trend-neta だけを対象に「Contents: Read and write」を許可した Fine-grained トークンを使ってください。トークンはこの端末のブラウザにだけ保存されます。

期限の14日前から画面上部でお知らせします。新しいトークンを貼り付けると、今日から90日後が自動で入ります（違う期限にした場合は直してください）。

トークンの更新方法

  1. Safari で GitHub のトークン一覧 を開く（ログイン画面が出たら cccdcccd でログイン）
  2. 一覧から今使っているトークン（例：trend-viewer-iphone）をタップ
  3. 「Regenerate token」をタップし、有効期限（Expiration）で「90 days」を選んで、もう一度「Regenerate token」をタップ
  4. 表示された github_pat_ で始まる文字列をコピー（この画面を閉じると二度と表示されません）
  5. このページに戻り、上の「GitHub トークン」欄に貼り付ける。有効期限が今日から90日後になっていることを確かめて「保存」をタップ

「Regenerate token」が見当たらないときは、一覧の「Generate new token」で作り直します。「Repository access」は「Only select repositories」で trend-neta だけ、「Permissions」は「Contents」を「Read and write」にしてください。作り直した場合は、古いトークンを一覧から削除（Delete）してください。
